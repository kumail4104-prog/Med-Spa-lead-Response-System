# Med-Spa-lead-Response-System
A practical lead response and appointment recovery system designed to help med spas respond faster and manage more booking opportunities.

## Business problem

When enquiries go unanswered or missed calls are not returned, potential clients may book elsewhere. This project focuses on helping a med spa keep track of those enquiries and follow up with people who still want an appointment.

## Project goal

Build a demo system for a fictional med spa that captures enquiries, keeps lead details organized, and helps the team follow up on booking opportunities. The demo will use sample data, with test results documented as each part is built.
